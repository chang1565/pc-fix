# 문제 해결 콘텐츠 개정: 2026-10-18

## 범위

- 한국어 원문: 증상 217개 + 오류 코드 80개.
- 한국어·영어·일본어·중국어의 상세 페이지 총 1,188개에 같은 구조 적용.
- 기존 URL, 검색어·별칭, 관련 링크와 canonical 유지.

## 구조

`data/problemDiagnostics.json`에는 증상별로 작성한 첫 확인 항목과 두 가지 결과 분기가 들어 있다. 각 항목은 `확인 → 결과별 조치 → 지속 실패·중단 조건`의 순서로 표시한다. 문장만 바꾼 공통 원인 목록으로 대체하지 않는다.

증상 페이지의 공통 해결 절차는 개별 분기 뒤의 추가 점검으로 유지한다. 고장 의심 HDD의 클릭음과 BitLocker 복구 키 페이지는 일반 복구 절차로 진행하지 않도록 별도 경로만 제공한다. FAQ의 첫 확인·결과 답변도 해당 증상의 분기를 사용한다.

`data/errorDiagnostics.json`에는 오류 80개 각각의 사전 판단과 조치 실패 시 다음 행동이 들어 있다. 오류 페이지는 기존 두 개 섹션을 다음 네 섹션으로 구분한다.

1. 발생 조건과 먼저 할 일: 코드별 확인 사항·중단 조건.
2. 첫 번째 조치: 기존의 첫 조치와 재시도 판단.
3. 해결되지 않았을 때의 조치: 후속 조치와 오류별 확인 기준.
4. 결과 확인과 다음 행동: 실제 기능 검증·실패 시 점검 범위·기록할 정보.

위험 신호, 기존 데이터, 조직 정책이 있는 경우에는 뒤에 있는 일반 조치를 무조건 계속하지 않도록 안내한다. 공통 조치 재사용 자체를 없앤 작업은 아니다. 각 증상에 대한 실제 분기와 결과 판단을 먼저 제공하는 개정이다.

## 번역

새 문장은 기존 번역 생성 도구로 저장했다. 드라이버 용어, 명령어·오류 코드 보존을 검사했다. 고장 HDD, 미할당 디스크, 팽창 배터리, BitLocker, CPU 보호 기능, 네트워크 공유의 핵심 문장은 3개 언어에서 따로 검토·수정해 uiOverrides.json에 보존했다.

모든 외국어 문장에 대한 원어민 편집 검수나 모든 고장 상황의 실물 재현을 완료한 것은 아니다. 검토일은 콘텐츠 개정일이며 모든 장치에서 실험했다는 의미가 아니다. 실제 테스트·수리 경험을 만들어 기재하지 않는다.

## 유지·검증

- 새 증상·코드 추가 시 해당 진단 JSON도 추가한다. 누락은 생성 단계에서 실패한다.
- `node scripts/check-guidance.mjs`: 297개 분기 누락·잘못된 키, 단계 순서, 빈 조치, 개별 분기 중복, 위험 상황의 일반 복구 경로, 외국어 누락·명령어 변형을 검사한다.
- `node scripts/check-locales.mjs`: 기존 검색·링크·오류 코드·번역 회귀 검사.
- `npm run lint`, `npm run build` 실행 후 생성 HTML의 본문을 확인한다.
- 재심사 승인을 보장하는 변경은 아니다. 화면 자료·출처 확충·원어민 검수는 별도 작업이다.
