# 2026-11-14 사이트 개선 (C안)

계획과 근거 데이터: `work/site-improvement-plan-2026-11-14.md`(커밋 대상 아님). Search Console 기준 한국어 페이지 색인 39/321, 색인된 574개 중 553개가 10/18 이전 수집분이었다. 수동 조치·보안 문제는 없었다.

## 변경

- **개인정보처리방침(4개 언어):** "향후 사용할 수 있다"는 가정형 문구를 실제 동작에 맞췄다. AdSense 광고와 제3자 쿠키, 맞춤 광고 해제 경로(Google 내 광고 센터, aboutads.info), Cloudflare·서버 접속 기록, `pcfix-language` 쿠키(최대 1년), 검색어의 `?q=` 보관, 별도 통계 도구 미사용을 적었다.
- **광고 영역:** 좌우 세로 광고는 1200×720 이상 화면의 고정 위치에서만 표시한다. 좁은 화면에서는 숨기며, 숨긴 슬롯은 광고를 요청하지 않는다. `data-ad-status="unfilled"`인 자리는 접는다.
- **홈 국가별 자동 이동 제거:** `/`는 접속 국가와 관계없이 한국어 홈(x-default)을 보여준다. 언어 메뉴에서 직접 고른 언어 쿠키가 있을 때만 이동한다. 해외 방문자에게는 `LanguageSuggestion` 안내 띠만 띄운다. Googlebot이 미국에서 `/`를 수집하면 `/en`으로 이동되던 문제를 없앴다.
- **한국어 직접 작성 안내 20개:** `data/koGuides/batch1~4.ts`. 3개월 노출 상위 한국어 증상 16개, 오류 4개다. 템플릿 공통 단계 대신 증상별 구분 질문, 원인, 메뉴 경로·명령, 결과별 다음 행동, 공식 출처를 담았다. `lib/koGuide.ts`가 한국어 페이지에서만 기존 내용을 대체한다.
- **한국어 카테고리 18개:** 소개 문단과 상황별로 먼저 볼 글 링크를 추가했다(`data/koGuides/categories.ts`).
- **사이트맵:** 위 한국어 페이지 38개만 lastmod를 2026-11-14로 바꿨다. 나머지는 2026-11-09 그대로다.

## 번역 페이지

C안에 따라 영어·일본어·중국어 본문은 바꾸지 않았다. 기존 `problems.ts`·`errorCodes.ts`는 번역 사전의 원문 키이므로 수정하지 않는다. 생성기는 `@/lib/koGuide`를 `@/lib/noKoGuide`로 바꿔 외국어 페이지에 한국어 안내가 섞이지 않게 한다. 새 화면 문구 번역은 `data/locales/uiOverrides.json`에 있다.

## 검증

- `check-errors`, `check-locales`, `tsc`, `lint`(기존 경고 1개), `build` 통과.
- `check-rendered-indexing`: 1,284페이지 통과. 한국어 안내 페이지는 화면의 검토일과 사이트맵 날짜가 일치하는지 함께 검사한다.
- 로컬 운영 모드에서 확인한 것:
  - `/`: US·JP 접속 200(한국어), `ja` 쿠키가 있으면 `/ja`로 307 이동(검색어 유지).
  - 안내 띠에서 영어로 이동하면 쿠키가 저장되고 띠가 사라진다.
  - 모바일 375px에서 좌우 광고는 높이 0, 1400px에서는 고정 위치로 그대로 나온다.

원고의 메뉴 이름 일부(한국어 Windows UI 표기)는 실제 한국어 화면과 대조하지 않았다. 버전에 따라 다를 수 있다고 본문에 적었다. 이 변경이 색인 회복을 보장하지 않는다.
