# 해결 절차 전수 편집

## 범위와 기준

- 한국어 원문 증상 217개, 오류 코드 80개. 번역 상세 포함 1,188페이지.
- 공통 조치 198종의 실행 문장·결과 판단과 증상별 진단 651문장, 오류별 사전·실패 분기 160문장을 검토했다. 재사용하는 조치는 한 원본에서 수정하고 모든 사용 페이지에 적용했다.
- 증상 상세 1,381섹션(개별 진단 217 + 후속 조치 1,164), 오류 상세 320섹션에 적용한다. 모든 섹션이 서로 다른 새 글이라는 뜻은 아니다.
- `docs/search-ctr.md`에 기록된 2026-10-07~13 노출 상위 검색어 9종을 기준 사례로 사용했다. 현재 시점의 새 노출 순위를 조회한 결과는 아니다.
- 기준 사례: ERR_CACHE_MISS, Error 1722, ERR_NETWORK_CHANGED, 0x800736B1, ERR_NAME_NOT_RESOLVED, SYSTEM_SERVICE_EXCEPTION, 0x8024200D, DXGI_ERROR_DEVICE_RESET, DXGI_ERROR_INVALID_CALL.

## 편집

- `procedureReview.json`: 198종의 확인 위치·실행 절차·결과별 다음 행동. 기존 `solutionOutcomes.json`을 대체한다.
- `errorProcedureReview.json`: 80코드의 조치별 확인 위치와 첫 조치의 판정 기준. 기준 사례 9종은 메뉴·로그·비교 조건을 포함한 실행 문장도 별도 편집했다.
- UI에서 확인할 곳을 조치 앞에 표시하고, 결과 판단과 다음 행동을 뒤에 표시한다. 첫 증상별 진단의 세 문장은 확인 → 결과 분기 → 지속 실패·중단 순서로 유지한다.
- GPU 점검에 디스크 안내, 컨트롤러 점검에 회선 안내, DNS 캐시 점검에 DHCP 안내가 섞인 문맥 오류를 수정했다.
- 충전 보고서 실행·읽기, 메모리 검사 결과 위치, GPU 지원 재설치, 설치 실패 로그·어셈블리 아키텍처, 게임 파일 검사, 프린터 대기열을 구체화했다.
- 고정 IP·조직망·원격 연결에서 네트워크 초기화를 무조건 실행하지 않는다. 진단 전에 파일·복구 키·재구성 정보를 확보한다. 보안 보호·서명 검사를 일괄 해제하지 않는다.
- 모바일 관련 카드의 긴 오류 코드가 그리드 최소 폭을 밀어내던 현상을 수정했다. 카드 최소 폭과 긴 단어 줄바꿈을 조정한다.
- 같은 실행 문장은 한 페이지에서 중복 표시하지 않는다. 동일 코드의 다른 의미(Installer 1722와 RPC 1722)를 구분한다.
- 추가 출처 링크·실물 화면·실험 경험을 새로 만들지 않았다. 기존 참고 영역은 유지한다.

## 번역과 검증

- 4개 언어 재생성. 명령어·도구명·아키텍처 식별자의 보호·검사를 확대했다.
- 배터리 완충 용량, HDD 클릭음, 조직 관리자 요청, 원격 접속 중 연결 해제의 주의 문구를 3개 번역에서 따로 교정했다.
- `node scripts/check-guidance.mjs`: 모든 진단·조치 카탈로그 연결, 누락·중복·위험 분기·번역 누락 검사.
- `node scripts/check-locales.mjs`: 검색·별칭·코드·링크·명령어·4언어 검사.
- `npm run lint`, `npm run build`, `node scripts/check-rendered-guidance.mjs`.
- 마지막 검사는 생성된 상세 HTML 1,188개에서 위치·실행 문장·결과·canonical이 실제 출력되는지 확인한다.
- 모바일·PC의 검색→상세 흐름, 대표 증상·코드·위험 상태 페이지를 화면으로 확인하고 배포 후 라이브에서 다시 확인한다.

모든 고장을 실물로 재현했다거나 번역 전체에 원어민 감수를 받았다는 뜻은 아니다. 검토일은 원문과 절차를 편집한 날짜다.
