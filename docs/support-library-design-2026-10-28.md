# PC FIX — 선택된 B안 적용

## 후속 수정: 아이콘 테마

사용자 요청으로 제품 사진을 SVG 선형 아이콘 5개로 교체하고 사진 자산을 삭제했다. ‘지금 어떤 상태인가요?’ 접이식 영역도 네 언어 홈에서 제거했다. 검색창·여백·테두리를 정리했다. 데스크톱과 390px 모바일에서 아이콘 배치·가로 넘침 없음을 확인했고, 빌드·린트·사이트 품질·색인·번역 검사를 통과했다. 아래는 첫 B안 적용 당시 기록이다.

- 흰색·파랑 기반 헤더, 중앙 검색, 기기별 탐색, 대표 해결 방법과 오류 코드의 두 열 구성.
- 본체·모니터·공유기·헤드셋·컨트롤러를 한 장의 투명 제품 이미지로 생성. 장식용 분류 이미지이며 실제 수리 사례 사진이 아니다.
- 원본 자산: `public/images/support-devices.png` (884,626 bytes). Next Image가 화면 크기에 맞게 제공한다.
- 기기와 분류 연결을 수정했다. 오류 코드 설명은 시안의 생성 문구를 쓰지 않고 검증된 오류 코드 데이터에서 가져온다.
- 한국어·영어·일본어·중국어 UI 동기화. 기존 가이드 본문·검색 알고리즘·URL·언어 전환을 유지한다.
- 로컬 브라우저: 데스크톱/390px 모바일, 이미지 로딩, 가로 넘침 없음, 검색 버튼, 0xc0000005의 정확한 결과 확인.
- 빌드/TypeScript/린트 통과. 기존 콘텐츠·언어·링크·정규 주소·초기 HTML 검사로 본문 보존을 검증한다.
